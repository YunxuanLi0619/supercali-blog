Benchmark是什么？
专业术语：一套标准化的测试，用来比较不同模型或在同一任务上的表现。

包括了：测试数据（数据从哪里来？）输入格式（模型看到什么？）输出格式（模型要回答什么？）评分规则（怎么样算对？）运行环境（是浏览器答题？还是调用工具，运行代码？访问文件？）汇总方式（最终分数是准确率，通过率，胜率，还是人类偏好？）

benchmark是一套完整的协议。

常见的benchmark

| 类型   | benchmark     | 主要测什么             |
| ---- | ------------- | ----------------- |
| 知识考试 | MMLU          | 多学科知识与选择题能力       |
| 代码生成 | HumanEval     | 根据说明写函数并通过测试      |
| 真实工程 | SWE-bench     | 修理真实的github issue |
| 高难推理 | GPQA          | 研究生级别科学回答         |
| 综合评测 | HELM          | 多场景，多指标表现         |
| 人类偏好 | chatbot Arena | 用户更喜欢哪个模型         |
| 系统性能 | MLperf        | 训练/推理速度与部署表现      |
|      |               |                   |
组成：
一、任务：
想测什么能力？
二、数据：
数据是题目来源
三、输入输出格式：
四、评分规则：
准确率，通过率，胜率，排名分，多指标评分（鲁棒性，公平性，偏见性，效率，毒性）。
五、运行环境：
环境越复杂，越接近真实系统，复现难度越高。这些条件影响分数
